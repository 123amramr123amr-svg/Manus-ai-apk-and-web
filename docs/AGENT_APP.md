# تطبيق الوكيل المستقل — بديل OpenManus على الجوال / Standalone agent APK

<div dir="rtl">

## السؤال: هل يمكن تحويل OpenManus نفسه إلى APK؟

**الإجابة المختصرة: لا، ليس كما هو.** إليك الأسباب الفنية الدقيقة (من مستودع OpenManus):

| المتطلب في OpenManus | الوضع على أندرويد |
| --- | --- |
| Python 3.12 + حزمة ضخمة (`playwright`, `crawl4ai`, `browsergym`, `datasets`, `docker`, `gymnasium`…) | لا يوجد مفسّر Python كامل على أندرويد، وتثبيت هذه الحزم مستحيل عمليًا |
| متصفح آلي (Playwright/Chromium + Browser Use) | Playwright **لا يدعم أندرويد** إطلاقًا (سطح مكتب فقط) |
| صندوق رملي Docker (`[sandbox]`) | لا يوجد Docker داخل تطبيق أندرويد |
| واجهة: سطر أوامر (`python main.py`) + خادم MCP | لا توجد واجهة موبايل أصلًا |

لذلك أي «تحويل» مباشر سيفشل. الحل العملي هو **إعادة بناء نفس الفكرة** كتطبيق يعمل على الجهاز.

## ما الذي بنيناه بدلًا منه؟

تطبيق **الوضع المستقل** داخل نفس الـ APK: وكيل ذكاء اصطناعي كامل يعمل **بدون أي خادم**،
ويحتاج فقط **مفتاح LLM خاص بك** (وليس مفتاح Manus، ولا أي مفتاح من الشركة).

**كيف يعمل؟** تحقّقنا فعليًا (اختبار CORS) أن كل هؤلاء المزودين يسمحون بطلبات مباشرة من التطبيق:

## ما يستطيع الوكيل فعله (الأدوات)

</div>

| الأداة | الوظيفة | تحتاج مفتاحًا؟ |
| --- | --- | --- |
| `web_search` | بحث حقيقي في الويب (DuckDuckGo) وإرجاع عناوين وروابط ومقتطفات | لا |
| `read_url` | قراءة أي صفحة وتحويلها لنص منظّم (Markdown) | لا |
| `wikipedia` | بحث وملخّص من ويكيبيديا (عربي/إنجليزي) | لا |
| `calculate` | حسابات رياضية دقيقة | لا |
| `current_time` | التاريخ والوقت (مع منطقة زمنية) | لا |
| `save_note` / `list_notes` | حفظ ملاحظات ومسودات على الجهاز | لا |

<div dir="rtl">

**حلقة العمل (Agent loop):** يخطّط الوكيل → يستدعي أداة → يقرأ النتيجة → يعيد التخطيط (حتى 12 خطوة قابلة للضبط)
→ ثم يقدّم إجابة نهائية بالعربية مع المصادر. كل استدعاء أداة يظهر في الواجهة كبطاقة (يعمل/تم/فشل) مع نتيجته.

## طريقة الاستخدام (من داخل التطبيق)

1. ثبّت الـ APK وافتحه — سيفتح مباشرة على **الوضع المستقل** (بدون سؤال عن أي خادم).
2. اضغط ⚙ الإعدادات → اختر المزوّد (مثلًا DeepSeek أو OpenRouter) → ألصق **مفتاحك** → **اختبار الاتصال**.
3. اكتب مهمتك في الأسفل، مثال:
   * «ابحث لي عن آخر أخبار الذكاء الاصطناعي ولخّصها في 5 نقاط»
   * «اقرأ صفحة github.com/FoundationAgents/OpenManus ولخّصها»
   * «قارن بين أفضل 3 هواتف تحت 500 دولار»
4. يمكنك: إيقاف التنفيذ، نسخ الإجابة، تصدير المحادثة (Markdown)، والرجوع لمحادثات سابقة من ☰.

> في وضع الخادم (من الإعدادات → «تبديل الوضع») يمكنك إدخال رابط خادم Manus AI / OpenManus الذي تنشره بنفسك.

## الخصوصية والأمان

* المفتاح والمحادثات تُخزَّن في **جهازك فقط** (`localStorage`) ولا تمرّ بأي خادم وسيط.
* الطلبات تذهب مباشرة إلى مزوّد الموديل الذي اخترته.
* لا توجد تتبّعات أو تحليلات في التطبيق.
* أدوات البحث/القراءة تستخدم خدمة قراءة عامة (r.jina.ai) بدون مفاتيح — الرابط الذي تطلبه الوكيل يمرّ عبرها.

## الحدود (بصراحة)

* لا يوجد **متصفح آلي حقيقي** (فتح صفحات، تسجيل دخول، تعبئة نماذج) كما في OpenManus/Playwright — لأن أندرويد لا يدعم ذلك.
  البديل: `web_search` + `read_url` اللذان يغطيان معظم مهام البحث والتلخيص.
* لا يوجد **صندوق رملي لتشغيل الأكواد** (Docker). إن أردت تشغيل الأكواد فعليًا فاستخدم وضع الخادم.
* جودة النتائج تعتمد على الموديل الذي تختاره (موديلات الأدوات مثل `deepseek-chat` أو `gpt-4o-mini` أو
  `gemini-2.5-flash` تعمل جيدًا وتكلفتها منخفضة).

## بناء الـ APK

</div>

```bash
# بدون Gradle (الأسرع)
export ANDROID_SDK_ROOT=~/Android/Sdk
VERSION_NAME=1.1.0 VERSION_CODE=2 ./android/build-manual.sh dist/manus-ai-1.1.0-debug.apk

# أو مع Gradle / Android Studio
cd android && gradle assembleDebug
```

<div dir="rtl">

الأصول المدمجة داخل الـ APK تُنسخ من `web/agent/` بالأمر `go run ./tools/syncassets`،
ويوجد اختبار تلقائي يفشل إذا اختلفت النسختان: `go test ./web/`.

## اختبارات الجودة

</div>

```bash
go test ./...                        # كل اختبارات Go (خادم + تماسك الواجهات + مزامنة الأصول)
```

## تشغيل نفس الوكيل من المتصفح (بدون APK)

بعد نشر خادم Go: افتح `https://<نطاقك>/agent/` — نفس الواجهة بالضبط، وتعمل كـ PWA على الجوال.
(الخادم نفسه لا يحتاج أي مفتاح لهذا الوضع؛ المفتاح يبقى في متصفح المستخدم.)
