# أول تشغيل: ماذا أكتب في خانة «عنوان الخادم»؟ / First run

<div dir="rtl">

عند أول تشغيل لتطبيق الأندرويد تظهر نافذة **«خادم Manus AI»** تطلب عنوانًا. هذا طبيعي:
الـ APK عبارة عن **واجهة** فقط، ويحتاج إلى **خادم تطبيق الويب** (تطبيق Go في هذا المستودع) ليتصل بـ Manus.

> **لماذا لا يعمل التطبيق وحده؟** لأن `api.manus.ai` لا يسمح لصفحات الويب (أو الـ WebView) بالاتصال به مباشرة —
> فحص CORS يمنع ذلك (لا تُعاد ترويسات `Access-Control-Allow-*` في طلب الـ preflight). لذلك لا بد من خادم وسيط.

اختر أحد الحلول الثلاثة، ثم اكتب العنوان في الخانة واضغط **حفظ**.

</div>

---

## الحل 1 — تشغيل الخادم على حاسوبك (أسرع تجربة، بدون حساب أو نشر)

<div dir="rtl">

1. ثبّت [Go 1.22+](https://go.dev/dl/) على الحاسوب، أو استخدم Docker.
2. شغّل الخادم:

</div>

```bash
# من مجلد المستودع (بعد استنساخه)
go run ./cmd/manusweb
# أو باستخدام Docker
docker build -t manus-ai-web . && docker run --rm -p 8080:8080 manus-ai-web
```

<div dir="rtl">

3. اعرف عنوان IP لحاسوبك داخل الشبكة:

</div>

```bash
# Windows
ipconfig        # ابحث عن IPv4 Address مثل 192.168.1.5
# macOS / Linux
ifconfig | grep "inet "
```

<div dir="rtl">

4. اكتب في نافذة التطبيق:

</div>

```text
http://192.168.1.5:8080
```

<div dir="rtl">

(بدّل `192.168.1.5` بعنوان حاسوبك، واحتفظ بـ `http://` والبورت `8080`).

5. شروط: **الهاتف والحاسوب على نفس شبكة الواي فاي**، وأن يسمح جدار الحماية بالمنفذ 8080.
   * إن كنت على بيانات الجوال (4G) فلن يعمل هذا الحل — استخدم الحل 2.
   * إن نجح الاتصال ستظهر واجهة التطبيق، ثم افتح ⚙ الإعدادات وألصق مفتاح Manus API واضغط **اختبار الاتصال**.

</div>

---

## الحل 2 — نشر مجاني على السحابة (يعمل من أي مكان) — الأفضل

### أ) Render بنقرة واحدة

<div dir="rtl">

المستودع يحتوي `render.yaml`، لذلك:

1. تأكد أن ملفات المستودع مرفوعة على GitHub (نعم، هي مرفوعة).
2. اذهب إلى: <https://render.com/deploy?repo=https://github.com/123amramr123amr-svg/Manus-ai-apk-and-web>
3. سجّل دخول بـ GitHub ← اضغط **Apply / Deploy**.
4. انتظر 3–5 دقائق حتى يظهر الرابط مثل:
   `https://manus-ai-web.onrender.com`
5. اكتب هذا الرابط في نافذة التطبيق ← **حفظ**.

> الخطة المجانية تُنيم الخادم بعد ~15 دقيقة خمول، فأول فتح بعد ذلك يستغرق 30–60 ثانية. اترك `MANUS_API_KEY` فارغًا
> لتُدخل مفتاحك من داخل التطبيق.

</div>

### ب) بدائل مجانية أخرى

| المنصة | الطريقة |
| --- | --- |
| **Fly.io** | `fly launch --dockerfile Dockerfile` ثم `fly deploy` |
| **Railway** | New Project → Deploy from GitHub repo → يكتشف `Dockerfile` تلقائيًا |
| **Koyeb** | Create Service → GitHub → Docker → Port 8080 |
| **VPS خاص** | `go build -o manusweb ./cmd/manusweb` ثم systemd (انظر `docs/DEPLOY_WEB.md`) |

<div dir="rtl">

في كل الحالات ستحصل على رابط مثل `https://xxxx.example.com` — هذا ما تكتبه في خانة عنوان الخادم.

</div>

---

## الحل 3 — لا تستخدم الـ APK أصلًا (PWA)

<div dir="rtl">

بعد تنفيذ الحل 1 أو 2 واحصلت على رابط للخادم:

1. افتح الرابط في **Chrome** على الهاتف.
2. قائمة النقاط الثلاث ← **تثبيت التطبيق / إضافة إلى الشاشة الرئيسية**.
3. سيُثبَّت بنفس الواجهة والأيقونة وبدون أي نافذة "عنوان الخادم".

</div>

---

## بعد الاتصال: الخطوات التالية

<div dir="rtl">

1. من التطبيق: ⚙ **الإعدادات** ← ألصق **مفتاح Manus API** (تحصل عليه من حسابك في Manus: Settings → API Keys).
2. اضغط **اختبار الاتصال** — يجب أن تظهر رسالة نجاح مع رصيدك.
3. تبويب **محادثة** ← افتح «+ مهمة جديدة» ← اكتب طلبك ← **إنشاء المهمة**.
4. تابع الردود (تُحدَّث تلقائيًا)، ويمكنك إرفاق ملفات، أو إرسال رسائل إضافية، أو إيقاف المهمة.

</div>

## حلول سريعة للمشاكل الشائعة

| ما تراه | السبب والحل |
| --- | --- |
| تظهر صفحة «لا يمكن الوصول إلى الخادم» | العنوان خطأ/الخادم متوقف. اضغط «عنوان الخادم» لتعديله، ثم «إعادة المحاولة». |
| `http://localhost:8080` لا يعمل على الهاتف | `localhost` يعني الهاتف نفسه. استخدم IP الحاسوب مثل `http://192.168.1.5:8080`. |
| يعمل على الواي فاي ولا يعمل على 4G | طبيعي في الحل 1 (شبكة محلية). انشر على السحابة (الحل 2). |
| يتصل لكن الطلبات تفشل بـ 401 | مفتاح API غير صحيح أو غير موجود — أعد إدخاله في ⚙ الإعدادات. |
| Render يفتح ببطء أول مرة | الخطة المجانية تنام بعد خمول؛ انتظر نصف دقيقة. |
| شريط فيه `sha256:...` عند التحميل | هذا من صفحة GitHub (بصمة الملف)، لا علاقة له بالتطبيق. |
